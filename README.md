# Thrainax E-Commerce

Build a professional Thrainax Internship E-Commerce Web Application with minimum AI credit usage.

Technologies

- Frontend: React + TypeScript + Tailwind CSS

- Backend: Java + Spring Boot

- API: REST APIs

- Database: MySQL

- ORM: Spring Data JPA / Hibernate

- Authentication: Login/Register + Role-Based Access Control

- Tools: Git + GitHub

Features

User:

- Register/Login/Logout

- View, search and filter products

- Product details

- Add/update/remove cart items

- Checkout and place order

- View order history

- Track order status

Admin:

- Admin Dashboard

- Product CRUD: Add, View, Update, Delete

- Manage stock

- View customer orders

- Update order status

Backend

Use Controller → Service → Repository architecture.

Entities:

User, Product, Cart, CartItem, Order, OrderItem.

Implement:

- REST APIs

- Spring Data JPA

- MySQL relationships

- Validation

- Exception handling

- Authentication and authorization

- USER/ADMIN role protection

Frontend Pages

Home, Login, Register, Products, Product Details, Cart, Checkout, My Orders, Order Tracking, Admin Dashboard.

Make it responsive, clean and professional for internship submission.

Important

Do NOT use Firebase, Supabase or Node.js backend. The backend must be Java + Spring Boot + MySQL.

Use reusable components and avoid unnecessary libraries, animations and duplicate code.

Credit-saving: Build only the required features, don't regenerate working files, and don't add unnecessary features.
